# SayLoud

[English](README.md) · **中文** · [日本語](README.ja.md)

SayLoud 让 Chrome 朗读网页。它会高亮当前正在朗读的句子,如果使用的语音支持词级时间戳,还会逐词高亮。

![SayLoud 正在朗读一个网页](assets/reading.png)

## 它能做什么

- **简洁的控制条,而非复杂的设置面板。** 点击工具栏图标,页面右侧会滑出一条 28px
  的控制条:播放/暂停、上一句/下一句、语速调节、显示剩余时间的进度环、字幕窗口开关,以及快速访问设置的入口。
- **所有语音都支持句级高亮,部分支持词级高亮。** 每种语音都会高亮当前句子。当语音提供词级时间戳时,会逐词点亮正在朗读的单词。
- **从任意句子开始朗读。** 点击页面上的任意句子,就从那里开始朗读。
- **语速 0.5×–3×，音量 0–150%。** 两者都对正在朗读的这一句立即生效。
- **切走标签页也不会停。** 你可以去别的标签页干活，这边继续读。
- **智能自动滚动。** 页面会跟随朗读位置自动滚动,但只要你手动滚动,自动滚动就会暂停,并显示一个跳回当前句的按钮。
- **浮动字幕窗口** —— 在一个可移动、始终置顶的窗口中显示当前句子和朗读进度。
- **开箱即用。** 浏览器内置语音无需账号、无需 API 密钥、无需联网。

## 三种被朗读的方式

| | 所需条件 | 隐私保护 | 词级高亮 |
|---|---|---|---|
| **浏览器内置语音** | 无 | 完全本地 —— 使用系统自带语音合成 | 来自浏览器的词事件 |
| **本地模型** | 一次性下载 | 完全本地 —— 在浏览器中运行 | 仅句级 |
| **云服务** | 你的 API 密钥 | 仅发送到你选择的服务 | 来自服务返回的时间戳 |

### 本机运行

从 Models 标签页一次性下载 Kokoro 82M:41 种音色,覆盖英语(en-US、en-GB)、中文(zh-CN)和日语(ja)。提供三个档位(92 MB、163 MB、326 MB),可选 WebGPU 或 CPU 运行 —— 标签页会根据你的设备推荐最适合的选项。各音色在首次使用时下载。你的文本不会离开本地设备,也无需 API 密钥。

<img src="assets/panel-models.png" width="300" alt="Models 标签页：下载源、模型与档位">

### 云服务

使用你自己的 API 密钥接入 OpenAI 兼容服务(包括本地运行的 Kokoro-FastAPI)、ElevenLabs、Azure Speech、DashScope(阿里云百炼)的 CosyVoice 与 Qwen-TTS,或火山引擎豆包。支持返回词级时间戳的服务可实现逐词高亮,其他服务则使用句级高亮。密钥保存在 Chrome 的本地存储中,SayLoud 仅在你为某个服务配置时才请求相应的站点访问权限。

<img src="assets/panel-settings.png" width="300" alt="Settings 标签页：声音服务列表与表单">

## 怎么用

1. 打开一个网页,点击工具栏中的 SayLoud 图标。在你主动激活之前,扩展不会向页面注入任何内容 —— 它不会自动访问你浏览的页面。
2. 控制条出现在页面右侧。按播放键,或直接点击页面上的任意句子从该处开始朗读。
3. 打开侧边栏面板,查看朗读进度并调整语音、缓存和模型设置。

<img src="assets/panel-reading.png" width="300" alt="Reading 标签页：语速、音量、字幕开关与进度">

字幕窗口从控制条打开,会将当前句子显示在其他窗口之上:

## 设置

- **语音** —— 为每个服务提供可搜索的语音列表,并标明哪些语音支持词级时间戳。你也可以直接输入语音 ID。
- **语速、音量、字幕窗口** —— 这些是朗读过程中经常需要调整的选项,因此放在 Reading 标签页中便于快速访问。
- **界面语言** —— English、中文、日本語，或跟随浏览器。
- **缓存** —— 将合成的音频存储在本地,重复朗读相同句子时可即时播放。默认启用,可配置上限(50 / 100 / 200 / 500 MB,默认 200 MB),显示当前使用量,支持一键清空。
- **模型** —— 配置下载源(自动、Hugging Face、ModelScope 或自定义镜像)、模型档位以及运行设备(WebGPU 或 CPU)。

## 隐私

SayLoud 没有后端服务器,不收集任何数据。浏览器内置语音和本地模型完全在本地运行。如果你配置了云服务,文本会携带你的 API 密钥从浏览器直接发送到该服务 —— 不会发送到其他任何地方。站点访问权限仅在特定服务需要时才会请求,并且可以随时在 Chrome 的扩展设置中撤销。

## 安装

SayLoud 尚未上架 Chrome 应用商店。目前请安装打包好的版本:

1. 打开 `chrome://extensions`,开启**开发者模式**。
2. 在 [Releases 页面](https://github.com/hr3lxphr6j/sayloud/releases)的 **Assets** 里下载 `sayloud-<version>-chrome.zip`,把它拖到这个页面上 —— Chrome 会解开它并作为已解压的扩展安装。

如果拖放没反应,就把压缩包解压到一个单独的文件夹,点**加载已解压的扩展程序**,选择那个文件夹(里面有 `manifest.json` 的那个)。这个文件夹要留在原地:Chrome 是从它里面加载扩展的。

更新时:下载新的 zip,再拖一次即可。这个渠道没有自动更新,而且它是开发者模式安装,所以 Chrome 会一直显示开发者模式的提示。

想从源码构建(Node.js 22+、pnpm 9+、Rust 工具链,以及把一小段 Rust 代码编译为 WebAssembly 的 `wasm-pack`)见 [CONTRIBUTING.md](CONTRIBUTING.md)。

兼容当前版本的 Chrome。字幕窗口需要 Chrome 116 或更高版本;在旧版本上其他所有功能均正常工作,字幕开关会说明版本要求。

*Chrome 应用商店页即将上线。*
