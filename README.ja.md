# SayLoud

[English](README.md) · [中文](README.zh.md) · **日本語**

SayLoud は Chrome で Web ページを読み上げます。読んでいる文をハイライトし、
単語のタイミングを返す音声であれば、発音されている単語もひとつずつハイライトします。

![SayLoud がページを読み上げているところ](assets/reading.png)

## できること

- **設定画面ではなく、ページ上のバー。** ツールバーのアイコンをクリックすると、
  右端に 28px のバーが出ます。再生／一時停止、前の文／次の文、速度、残り時間つきの
  進捗リング、キャプションウィンドウ、設定への入口がここにあります。
- **文単位で、できるときは単語単位で。** 文のハイライトはどの音声でも効きます。
  音声が各単語の開始位置を返す場合は、話された単語が順に光ります。
- **文をクリックすればそこから。** 読み上げはページの先頭ではなく、
  クリックした文から始まります。
- **速度 0.5×–3×、音量 0–150%。** どちらも今読んでいる文にすぐ反映されます。
- **タブを離れても読み続けます。** 別のタブで作業しながら聞けます。
- **自動スクロールは譲ります。** ページは読み上げ位置についてきますが、
  自分でスクロールした瞬間に止まり、その文へ戻るボタンをカードで出します。
- **キャプションウィンドウは好きな場所に**——今の文と全体の何文目かを、
  常に手前に出る小さなウィンドウに表示します。
- **はじめから設定不要。** ブラウザ音声にはアカウントも API キーも通信も要りません。

## 3 つの読み上げ方

| | 必要なもの | テキストの行き先 | 単語ハイライト |
|---|---|---|---|
| **ブラウザ音声** | 何もいらない | どこにも送られない（OS の音声合成） | ブラウザ自身の単語イベントから |
| **この端末で** | モデルを一度ダウンロード | どこにも送られない（ブラウザ内で動く） | 文単位のみ |
| **クラウドサービス** | 自分の API キー | 設定したサービスだけへ | サービスが返すタイムスタンプから |

### この端末で

Kokoro 82M を「Models」タブから一度ダウンロードします。音声は 41 種類で、
英語（en-US、en-GB）、中国語（zh-CN）、日本語（ja）に対応。サイズは 92 MB、
163 MB、326 MB の 3 つで、WebGPU か CPU を選べます。どれが向いているかはタブが教えてくれます。
音声ファイルは最初に使うときに取得されます。テキストが端末の外に出ることはなく、
API キーも不要です。

<img src="assets/panel-models.png" width="300" alt="Models タブ：ダウンロード元、モデル、サイズ">

### クラウドサービス

自分の API キーで、OpenAI 互換サーバー（ローカルの Kokoro-FastAPI も含む）、
ElevenLabs、Azure Speech、DashScope（阿里云百炼）の CosyVoice と Qwen-TTS、
火山引擎豆包を利用できます。単語のタイミングを返すサービスでは単語単位、
返さないサービスでは文単位でハイライトします。キーは Chrome のストレージに保存され、
SayLoud がサイトへのアクセスを求めるのは、そのサイト用にサービスを設定したときだけです。

<img src="assets/panel-settings.png" width="300" alt="Settings タブ：音声サービス一覧と設定フォーム">

## 使い方

1. 記事を開き、ツールバーの SayLoud アイコンをクリックします。クリックするまで、
   拡張機能はページに何も注入しません——閲覧中のページへの常時のアクセス権は持っていません。
2. 右端にバーが出ます。再生を押すか、ページ内の好きな文をクリックしてそこから始めます。
3. サイドパネルを開くと、進捗、音声、キャッシュ、モデルの設定があります。

<img src="assets/panel-reading.png" width="300" alt="Reading タブ：速度、音量、キャプション、進捗">

キャプションウィンドウはバーから開きます。今の文を他のウィンドウの手前に表示します：

<img src="assets/caption.png" width="420" alt="キャプションウィンドウ：1 文と何文目か">

## 設定

- **音声** —— サービスごとに検索できる一覧。単語タイミング対応かどうかも表示されます。
  音声 ID を直接入力することもできます。
- **速度・音量・キャプションウィンドウ** —— 読み上げ中に触る設定なので、
  Reading タブに置いてあります。
- **表示言語** —— English、中文、日本語、またはブラウザに合わせる。
- **キャッシュ** —— 合成した音声を端末に保存し、同じ文をもう一度読むときに再合成しません。
  既定でオン。上限は 50 / 100 / 200 / 500 MB（初期値 200 MB）から選べ、
  使用量の表示とワンクリックの削除つきです。
- **モデル** —— ダウンロード元（自動、Hugging Face、ModelScope、自分のミラー）、
  モデルのサイズ、動かすデバイス。

## プライバシー

SayLoud は自前のサーバーを持たず、何も収集しません。ブラウザ音声とオンデバイスモデルは
完全に端末内で完結します。クラウドサービスを設定した場合、読み上げさせるテキストは
あなたのキーとともにブラウザからそのサービスへ直接送られ、他のどこにも送られません。
サイトへのアクセス許可を求めるのはサービスが必要とするときだけで、
Chrome の拡張機能設定からいつでも取り消せます。

## インストール

SayLoud はまだ Chrome ウェブストアに公開していません。現在はソースからビルドします。
2 ステップです：

```bash
pnpm install
pnpm build
```

`chrome://extensions` を開き、**デベロッパーモード**を有効にして、
**パッケージ化されていない拡張機能を読み込む**から `.output/chrome-mv3` を選びます。
Node.js 22 以降と pnpm 9 以降が必要です。ビルドでは小さな Rust モジュールを wasm に
コンパイルするため、Rust ツールチェーンと `wasm-pack`（`cargo install wasm-pack`）も必要です。

現在の Chrome で動作します。キャプションウィンドウには Chrome 116 以降が必要で、
それより古い場合は他の機能はそのまま使え、キャプションのスイッチがその旨を表示します。

*Chrome ウェブストアでの公開は準備中です。*
