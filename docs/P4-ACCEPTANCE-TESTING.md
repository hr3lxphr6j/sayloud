# P4 手动验收清单

**版本**: 0.4.0  
**分支**: `p4-local-models`  
**构建**: `pnpm build` → `.output/chrome-mv3/`（24 MB）

---

## 准备工作

1. 加载扩展：`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选 `.output/chrome-mv3/`
2. 打开控制台：`chrome://extensions` → SayLoud 的"检查视图：Service Worker"
3. 准备测试页面：
   - **中文页**：找一篇包含短句、长句、数字、英文混排的中文文章（如维基百科）
   - **英文页**：任意英文网站

---

## 关键验收项（必做）

### ✅ V16: 国内网络下载 ModelScope

**目的**：验证国内用户能正常下载模型

1. **关掉代理**（确保走真实国内网络）
2. 打开侧边栏 → 模型标签页
3. 下载源选"自动（推荐）"
4. 选一个档位（推荐 fp16，163 MB）点"下载"
5. **观察**：
   - 进度条正常增长
   - 控制台显示走的是 ModelScope（`modelscope.cn`）
   - **记录实际下载速度**（多少秒下完 163 MB）
6. 下载完成后**断网** → 选一个中文页朗读 → 应该能正常播放（完全离线）

**通过标准**：能下完，速度 > 500 KB/s，断网后能播放

---

### ✅ V22: 中文听感（最重要）

**目的**：验证自建音素化管线的质量

1. 找一篇中文文章，包含：
   - **短句**（5-10 字）
   - **长句**（30+ 字）
   - **数字**（"2024年"、"3.14"）
   - **中英混排**（"使用 Chrome 浏览器"）
2. 侧边栏 → 朗读标签页 → 音色选"婷婷"（或其他中文音色）
3. 点播放，**仔细听**：
   - ✅ 声调是否正确（不是平淡的机器人调）
   - ✅ 是否漏字、多字、串行
   - ✅ 数字和英文的处理是否自然
   - ✅ 整体是否可接受（以你愿意日常用为准）

**如果有明显问题**（声调错、漏字、不可用），告诉我具体哪句话有问题，我们把中文改成"实验性"或暂不提供。

## 功能验收（建议做）

### 3. 下载源切换

1. 模型 tab → 下载源改成"Hugging Face"
2. 删除已下载的档位
3. 重新下载 → 应该走 HF（`huggingface.co`），国内可能很慢或失败
4. **如果失败**：看到提示"无法连接，请尝试其他下载源"

### 4. Canonical 缓存（换源不重下）

1. 用"自动"下载一个档位（走 ModelScope）
2. 下载完成后，改成"Hugging Face"
3. **不应该重新下载**（缓存键是 canonical URL，与源无关）
4. 控制台应该显示"model already cached"

### 5. 删除与恢复

1. 删除当前正在使用的档位
2. 尝试播放 → 应该看到"模型未下载 · 去模型设置 ›"
3. 点链接 → 跳到模型 tab
4. 重新下载 → 播放恢复正常

### 6. 音色自动下载

1. 朗读 tab → 选一个中文音色（如"小美"）
2. 点播放 → **第一次会稍慢**（后台下载音色文件，~500 KB）
3. 控制台应该显示"downloading voice: af_sky"
4. 第二次播放同一音色 → 立即开始（已缓存）

### 7. 档位切换

1. 模型 tab → 下载两个档位（如 q8 + fp16）
2. 切换到 q8 → 播放 → 应该生效
3. 切换回 fp16 → 播放 → 应该生效
4. **观察速度差异**：fp16 应该明显快于 q8（如果有 WebGPU）

### 8. 设备信息

1. 模型 tab 底部 → 看"设备"一行
2. **有 GPU 的机器**：应该显示"WebGPU · Apple M3 Pro"（或你的 GPU 型号）
3. **无 GPU 的机器**：应该显示"WASM（无 GPU）"

### 9. 存储占用

1. 模型 tab 底部 → "存储占用"一行
2. 应该显示正确的 MB 数（模型 + 音色，不含音频缓存）
3. 删除一个档位 → 数字应该减少

### 10. 英文播放

1. 打开一个英文页
2. 朗读 tab → 音色选"af_heart"（英文音色）
3. 点播放 → 应该正常朗读，质量应该不错

### 11. 性能验收

1. **首句延迟**：点播放到听到第一个字 → 应该 < 2 秒（fp16 + WebGPU）
2. **稳态速度**：播放一段长文（50+ 句）→ 应该不卡顿、不断档
3. **缓存命中**：重播同一句 → 应该立即开始（从音频缓存）

## 已知问题（不算 bug）

1. **"Extension context invalidated"**：Service worker 被 Chrome 回收，刷新页面即可恢复（P1-P3 都有，不阻塞 P4）
2. **没有"准备中…"提示**：第一次合成会等 1-2 秒建 session，看起来像卡住（§4.3.1 说明了为什么没做）
3. **音色下载 UI 未实现**：只显示"音色按需下载"，没有"下载全部"按钮（T4 说明了为什么没做）
4. **删除按钮在 local provider 里消失了**：这是正确的（刚修的 bug）
