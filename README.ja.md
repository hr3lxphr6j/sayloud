# SayLoud

[English](README.md) · [中文](README.zh.md) · **日本語**

SayLoud は Chrome で Web ページを読み上げます。現在読んでいる文をハイライトし、単語のタイミングを返す音声であれば、発音されている単語もひとつずつハイライトします。

![SayLoud がページを読み上げているところ](assets/reading.png)

## できること

- **設定画面ではなく、シンプルな操作バー。** ツールバーのアイコンをクリックすると、右端に 28px のバーがスライド表示されます。再生／一時停止、前の文／次の文、速度調整、残り時間つきの進捗リング、キャプションウィンドウの切り替え、設定への入口が並んでいます。
- **すべての音声で文単位、対応していれば単語単位。** どの音声でも現在の文をハイライトします。音声が各単語の開始位置を返す場合は、話された単語が順に光ります。
- **任意の文から読み始められます。** ページ内の好きな文をクリックすると、そこから読み上げが始まります。
- **速度 0.5×–3×、音量 0–150%。** どちらも今読んでいる文にすぐ反映されます。
- **タブを離れても読み続けます。** 別のタブで作業しながら聞けます。
- **スマートな自動スクロール。** ページは読み上げ位置についてきますが、手動でスクロールした瞬間に停止し、現在の文へ戻るボタンが表示されます。
- **フローティングキャプションウィンドウ** ── 移動可能で常に手前に表示されるウィンドウに、現在の文と進捗を表示します。
- **すぐに使えます。** ブラウザ音声にはアカウントも API キーも通信も必要ありません。

## 3 つの読み上げ方

| | 必要なもの | プライバシー | 単語ハイライト |
|---|---|---|---|
| **ブラウザ音声** | なし | 完全にローカル ── OS の音声合成を使用 | ブラウザの単語イベントから |
| **オンデバイスモデル** | 一度だけダウンロード | 完全にローカル ── ブラウザ内で動作 | 文単位のみ |
| **クラウドサービス** | 自分の API キー | 選択したサービスのみへ送信 | サービスのタイムスタンプから |

### この端末で

「Models」タブから Kokoro 82M を一度ダウンロードします。音声は 41 種類で、英語(en-US、en-GB)、中国語(zh-CN)、日本語(ja)に対応。サイズは 92 MB、163 MB、326 MB の 3 つで、WebGPU か CPU を選べます ── タブがお使いの端末に最適なものを推奨してくれます。各音声ファイルは最初に使うときに取得されます。テキストが端末の外に出ることはなく、API キーも不要です。

<img src="assets/panel-models.png" width="300" alt="Models タブ：ダウンロード元、モデル、サイズ">

### クラウドサービス

自分の API キーで、OpenAI 互換サーバー(ローカルの Kokoro-FastAPI も含む)、ElevenLabs、Azure Speech、DashScope(阿里云百炼)の CosyVoice と Qwen-TTS、火山引擎豆包を利用できます。単語のタイミングを返すサービスでは単語単位、返さないサービスでは文単位でハイライトします。キーは Chrome のローカルストレージに保存され、SayLoud がサイトへのアクセスを求めるのは、そのサービス用に設定したときだけです。

<img src="assets/panel-settings.png" width="300" alt="Settings タブ：音声サービス一覧と設定フォーム">

## 使い方

1. Web ページを開き、ツールバーの SayLoud アイコンをクリックします。アクティブにするまで、拡張機能はページに何も注入しません ── 閲覧中のページへ自動的にアクセスすることはありません。
2. 右端にバーが表示されます。再生を押すか、ページ内の任意の文をクリックしてそこから始めます。
3. サイドパネルを開くと、進捗の確認や音声、キャッシュ、モデルの設定ができます。

<img src="assets/panel-reading.png" width="300" alt="Reading タブ：速度、音量、キャプション、進捗">

キャプションウィンドウはバーから開きます。現在の文を他のウィンドウの手前に表示します:

<img src="assets/caption.png" width="420" alt="キャプションウィンドウ：1 文と何文目か">

## 設定

- **音声** ── サービスごとに検索可能な一覧。単語タイミング対応かどうかも表示されます。音声 ID を直接入力することもできます。
- **速度・音量・キャプションウィンドウ** ── 読み上げ中によく調整する設定なので、Reading タブに配置して素早くアクセスできるようにしています。
- **表示言語** —— English、中文、日本語、またはブラウザに合わせる。
- **キャッシュ** ── 合成した音声を端末に保存し、同じ文をもう一度読むときに瞬時に再生します。デフォルトでオン。上限は 50 / 100 / 200 / 500 MB(初期値 200 MB)から選べ、使用量の表示とワンクリックでの削除に対応しています。
- **モデル** ── ダウンロード元(自動、Hugging Face、ModelScope、独自のミラー)、モデルのサイズ、実行デバイス(WebGPU または CPU)を設定できます。

## プライバシー

SayLoud は独自のバックエンドサーバーを持たず、データを一切収集しません。ブラウザ音声とオンデバイスモデルは完全にローカルで完結します。クラウドサービスを設定した場合、読み上げさせるテキストは、あなたの API キーとともにブラウザからそのサービスへ直接送られ、他のどこにも送られません。サイトへのアクセス許可を求めるのは特定のサービスが必要とするときだけで、Chrome の拡張機能設定からいつでも取り消せます。

## インストール

SayLoud はまだ Chrome ウェブストアに公開していません。現在はソースからビルドします。2 ステップです:

```bash
pnpm install
pnpm build
```

`chrome://extensions` を開き、**デベロッパーモード**を有効にして、**パッケージ化されていない拡張機能を読み込む**から `.output/chrome-mv3` を選びます。

**必要な環境:** Node.js 22 以降、pnpm 9 以降、Rust ツールチェーン、`wasm-pack`(`cargo install wasm-pack`)。ビルドでは小さな Rust モジュールを WebAssembly にコンパイルします。

現在の Chrome で動作します。キャプションウィンドウには Chrome 116 以降が必要です。それより古いバージョンでは他の機能はそのまま使え、キャプションの切り替えボタンがバージョン要件を表示します。

*Chrome ウェブストアでの公開は準備中です。*
