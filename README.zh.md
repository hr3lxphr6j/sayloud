# SayLoud

[English](README.md) · **中文** · [日本語](README.ja.md)

SayLoud 在 Chrome 里把网页朗读出来。正在读的那一句会高亮；如果所用声音带词级时间戳，
正在念的那个词也会跟着高亮。

![SayLoud 正在朗读一个网页](assets/reading.png)

## 它能做什么

- **页面上一条窄条，而不是一屏设置。** 点一下工具栏图标，页面右侧出现一条 28px
  的控制条：播放/暂停、上一句/下一句、语速、带剩余时间的进度环、字幕小窗，以及进入设置的入口。
- **句级高亮，能到词就逐词。** 句子是所有声音的基线；当声音能报告每个词的开始时，
  被念到的词会逐个点亮。
- **点哪句就从哪句开始。** 朗读从你点的那句开始，而不是从页面开头。
- **语速 0.5×–3×，音量 0–150%。** 两者都对正在朗读的这一句立即生效。
- **切走标签页也不会停。** 你可以去别的标签页干活，这边继续读。
- **自动滚动会让步。** 页面会跟着朗读位置滚动，而你自己一滚动它就停；
  同时在卡片里给你一个跳回当前句的按钮。
- **字幕小窗可以放到任何地方**——当前句子和它读到第几句，在一个置顶的小窗里。
- **开箱即用，零配置。** 浏览器内置声音不需要账号、不需要 key、不需要联网。

## 三种被朗读的方式

| | 需要什么 | 你的文字去哪 | 词级高亮 |
|---|---|---|---|
| **浏览器内置声音** | 什么都不需要 | 不出本机——用的是系统自带语音 | 来自浏览器自己的词事件 |
| **本机模型** | 下载一次模型 | 不出本机——模型在浏览器里跑 | 整句高亮 |
| **云服务** | 你自己的 API key | 只发给你配置的那家服务 | 来自服务返回的时间戳 |

### 本机运行

Kokoro 82M，在"Models"标签页里下载一次：41 个音色，覆盖英语（en-US、en-GB）、
中文（zh-CN）和日语（ja）。三个档位——92 MB、163 MB、326 MB——可选 WebGPU 或
CPU，标签页会直接告诉你哪档适合你的机器。音色在第一次用到时才下载。
文字不会离开你的电脑，也不需要任何 key。

<img src="assets/panel-models.png" width="300" alt="Models 标签页：下载源、模型与档位">

### 云服务

用你自己的 key 接入 OpenAI 兼容服务（包括本地跑的 Kokoro-FastAPI）、ElevenLabs、
Azure Speech、DashScope（阿里云百炼）CosyVoice 与 Qwen-TTS，或火山引擎豆包。
会返回词级时间戳的服务得到逐词高亮，其余则整句高亮。key 保存在 Chrome 自己的存储里，
而 SayLoud 只在你为某个服务配置时才向它申请站点访问权限。

<img src="assets/panel-settings.png" width="300" alt="Settings 标签页：声音服务列表与表单">

## 怎么用

1. 打开一篇文章，点工具栏里的 SayLoud 图标。在你主动点击之前，
   扩展**不会**注入任何东西——它对你看的页面没有常驻访问权。
2. 页面右侧出现控制条。按播放，或者直接点页面上任意一句从句首开始。
3. 打开侧边面板，看进度、选音色、管缓存和模型。

<img src="assets/panel-reading.png" width="300" alt="Reading 标签页：语速、音量、字幕开关与进度">

字幕小窗从控制条打开，会把当前句子浮在其他窗口之上：

<img src="assets/caption.png" width="420" alt="字幕小窗：当前句子与句号">

## 设置

- **音色** —— 每个服务一份可选列表，可搜索，并标出哪些音色支持词级时间戳；
  也可以直接填音色 id。
- **语速、音量、字幕小窗** —— 这三个是朗读中随时会调的，所以放在 Reading 标签页，
  点一下就够。
- **界面语言** —— English、中文、日本語，或跟随浏览器。
- **缓存** —— 合成好的音频留在本机，重复朗读同一句就不必再合成。默认开启，
  上限可选 50 / 100 / 200 / 500 MB（默认 200 MB），显示已用容量，一键清空。
- **模型** —— 下载源（自动、Hugging Face、ModelScope 或你自己的镜像）、
  模型档位，以及模型跑在哪个设备上。

## 隐私

SayLoud 没有自己的服务器，也不收集任何东西。浏览器内置声音和本机模型完全在本机完成。
如果你配置了云服务，要朗读的文字会带着你的 key 从浏览器直接发到那家服务，
不会发给任何第三方。站点访问权限只在服务需要时才申请，随时可以在 Chrome 的扩展设置里收回。

## 安装

SayLoud 还没有上架 Chrome 应用商店。目前从源码构建，两步：

```bash
pnpm install
pnpm build
```

然后打开 `chrome://extensions`，开启**开发者模式**，点**加载已解压的扩展程序**，
选择 `.output/chrome-mv3`。需要 Node.js 22 或更高版本、pnpm 9 或更高版本；
构建过程会把一小段 Rust 编译成 wasm，所以还需要 Rust 工具链和
`wasm-pack`（`cargo install wasm-pack`）。

当前版本的 Chrome 即可。字幕小窗需要 Chrome 116 或更高版本；低版本上其他功能照常朗读，
字幕开关会直接说明这一点。
