Kokoro 中文发音试听

同一个模型、同一个音色、同一句话，只改喂进去的音素串格式 —— 用来判断 P5 spec §1.2 的五个偏差到底哪个听得出来。

怎么听
  1. 每句先听三个：现状 → 全部对齐 → legacy 参考（训练目标）。 最后一个是我们想靠近的对象。
  2. 有差别再往下听 只修 A / B / C / D，看是哪一项在起作用。
  3. 最后听 阶段 2：v1.1-zh 换了模型和音色，与上面不是同一个声音， 只判断「是不是更自然」，不要拿音色做对比。

标 token 相同 的行， normalizer 之后喂给模型的 id 与「现状」逐位相同 —— 必然听不出差别， 可以跳过。这是用来验证这套试听方法本身的。
